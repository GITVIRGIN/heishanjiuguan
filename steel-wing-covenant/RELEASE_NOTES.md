# 钢翼盟约 v1.0.0

首次 GitHub 发行，基于已通过内部检查的 V8 剧情与界面版本。游戏以独立目录发布，仓库原有《黑山酒馆》入口继续保留。

## 本次版本

- 保留 Qwen 的对白润色，由 GPT 独立审核并修正人物称谓、物件交接、分支前后文与结局说明。
- 修正身份披露后的档案解锁，以及已听过相关信息的旧存档恢复。
- 拆分多人接话中的姓名栏，确保发言人、立绘与正文对应。
- 修正下井者衣袖、写入后换位的圈数、物件保管位置等分支连续性问题。
- 保留固定对话框、语义分页、首帧打字修复和随剧情切换的美术资源。

## 验证范围

- 275 条从真实初态出发的路线及 6 份历史存档通过回放，预期结局保持。
- 3528 个剧情节点、90 个选择点、256 个选项与 10 个终点纳入覆盖检查。
- 4266 份文本输入、5414 个语义分页通过检查；既有显示、场景切换、素材缓存与旧档结算检查通过。
- GitHub 发行的游戏运行文件与已验收版本逐文件校验一致；不需要构建或安装 npm 依赖。

自动检查覆盖结构与指定回放路径，未将其视为人工全流程体验验收。对白口味和阅读节奏仍可继续提出反馈。

## 游玩提示

GitHub Pages 与原私密站点的存档不会自动互通。下载版需要本机 HTTP 服务，操作见 README.md。
